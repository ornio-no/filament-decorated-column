# Changelog

All notable changes to `filament-decorated-column` will be documented in this file.

## v1.0.0 - 2026-10-20

Initial release. `DecoratedColumn` and `DecoratedEntry` are Filament 5 `TextColumn` and `TextEntry` with `Badge` and `Icon` decorations before or after the text. Ported from fatura-app's `App\Filament\Components\Decorated` with the same public API, so switching is a change of `use` statements.
